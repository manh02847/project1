# Lesson13 - Tìm hiểu về Layout

Project thực hành các nội dung chính của bài học:

- Layout mặc định: `Views/Shared/_NnmLayout.cshtml`
- Khai báo Layout chung: `Views/_ViewStart.cshtml`
- Custom Layout cho sản phẩm: `Views/Shared/_NnmLayoutProduct.cshtml`
- CSS riêng: `wwwroot/css/NnmLayoutProduct.css`
- JavaScript riêng: `wwwroot/js/NnmLayout.js`
- Area Admin: `Areas/Admin`
- Area Customer: `Areas/Customer`
- Route Area được khai báo trước route mặc định trong `Program.cs`

Các view `NnmProducts/Index`, `Search`, `Hots` chủ động chọn Custom Layout để minh họa việc một view có thể dùng layout khác với layout mặc định.
